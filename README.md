# FloraScan AI - Vegetable Disease Identification System using CNN

An end-to-end Machine Learning and Computer Vision application built using **Python**, **TensorFlow / Keras (MobileNetV2 Transfer Learning)**, and **Flask**. This system automatically classifies leaf diseases in supported vegetable crops and presents educational guidelines alongside full model performance evaluation metrics.

Designed and structured for **B.Tech Computer Science & Engineering (CSE) Machine Learning Project Evaluation**.

---

## 🥦 Supported Vegetable Crops & Conditions

The model is trained strictly on PlantVillage benchmark datasets for the following **2 Vegetable Species** across 5 pathological states:

1. **Tomato (*Solanum lycopersicum*)**:
   - `Early Blight` (*Alternaria solani*)
   - `Late Blight` (*Phytophthora infestans*)
   - `Healthy`
2. **Potato (*Solanum tuberosum*)**:
   - `Early Blight` (*Alternaria solani*)
   - `Healthy`

> *Note: The system explicitly restricts identification to supported vegetable species to ensure high accuracy and prevent false out-of-domain predictions.*

## 🚀 Quick Execution Guide

### 1. Run Comprehensive Test Evaluation Script
```bash
python test_evaluation.py
```

### 2. Train / Retrain CNN Model
```bash
python train.py --epochs 10 --arch mobilenet
```

### 3. Single Image Prediction CLI
```bash
python predict.py --image sample_leaf.jpg
```

### 4. Start Flask Web Server
```bash
python app.py
```
Open **`http://127.0.0.1:5000`** in your browser.
